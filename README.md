# Radiology Research Topic Generator

**From Research Ideas to Academic Titles**

موقع ويب ثنائي اللغة لطلاب الدراسات العليا والباحثين في الأشعة والتصوير الطبي. يوفّر أربع أدوات متصلة بخدمة Manus AI الحقيقية: توليد الموضوعات، تطوير الأفكار، تحسين العناوين، وإنشاء مسودة أولية للمقترح.

## التشغيل

المشروع مبني على Manus Webdev (React + TypeScript + Express + tRPC). في البيئة المُدارة يستخدم `pnpm dev` على المنفذ الذي توفره المنصة. أوامر الفحص والبناء: `pnpm check` و`pnpm test` و`pnpm build`.

يستدعي الخادم خدمة Manus المدمجة عبر متغيرات runtime التي توفرها المنصة؛ لا يحتاج إلى مفتاح OpenAI أو مفتاح مزود خارجي، ولا يرسل أي مفتاح إلى المتصفح. إذا لم تتوفر الخدمة، يعرض التطبيق خطأ واضحًا بدل نتائج تجريبية.

## البنية

- `client/src/pages/Home.tsx`: الواجهة العربية والإنجليزية، أدوات الإنشاء الأربع، النتائج والتفاصيل والمفضلة والطباعة.
- `client/src/index.css`: التصميم المتجاوب واتجاه RTL/LTR والطباعة.
- `server/routers.ts`: إجراءات tRPC لخدمات البحث.
- `server/research-ai.ts`: التحقق من المدخلات، اختيار نموذج Manus متاح، تعليمات التوليد، تحليل JSON وتحديد معدل الطلبات.
- `public/manus-routes.json`: بيان المسارات.
- `plan.md` و`TODO.md`: خطة التصميم والتنفيذ ومتطلبات المنتج.

تحفظ اللغة والمفضلات في LocalStorage على جهاز المستخدم؛ لا تحفظ الأفكار المدخلة في قاعدة بيانات. زر «حفظ بصيغة PDF» يفتح حوار الطباعة، ومنه اختر “Save as PDF”.

## الدقة وحدود الاستخدام

لا يبحث المنتج في PubMed أو Google Scholar أو أي قاعدة للدراسات السابقة، ولا يدعي إثبات الجِدّة. الاقتراحات ليست نتائج مثبتة ولا بروتوكولًا نهائيًا. يجب مراجعة الإمكانية والمنهجية والأخلاقيات وحجم العينة والجِدّة مع المشرف والإحصائي قبل اعتماد أي مقترح.

## التوسعة

فُصل توليد الذكاء الاصطناعي وواجهات الخادم عن عناصر الواجهة لتسهيل توسيع المنصة إلى تخصصات طبية إضافية.
